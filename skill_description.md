

## Skill-by-skill description

### 1. analyze-research-gaps
This skill is for finding gaps in a research area. It helps answer questions like: “What topics are underexplored?” or “What evidence is missing before a study should proceed?” It is best for corpus analysis and identifying where more literature or evidence is needed.

### 2. conduct-systematic-review
This is the most structured literature-review skill in the collection. It focuses on systematic review workflows: defining the question, creating a search strategy, screening sources, scoring quality, and synthesizing findings into themes. It is ideal when you want a more rigorous and reproducible review process.

### 3. synthesize-scientific-literature
This skill is oriented toward practical research execution. It emphasizes searching through scientific databases, checking citations, organizing findings, and generating review documents in markdown or PDF form. It is useful when your goal is to actually produce a literature review document.

### 4. plan-literature-review
This is a lighter, more compact literature-review framework. It is designed for planning and synthesizing research, covering the core review workflow without going as deep into methodological detail as the Borghei version. It is a good starting point for a quick academic review.

### 5. search-academic-sources
This skill is focused on literature discovery. It searches across multiple academic sources such as Semantic Scholar, OpenAlex, Crossref, and PubMed to find relevant papers and metadata. It is best when the main task is “find and gather the sources” rather than full review methodology.

### 6. identify-literature-gaps
This is a recovered or rendered version of a literature-gap skill that was originally available via a marketplace source. It is mainly useful as a reference or archival copy for understanding how gap analysis is framed and prioritized.
